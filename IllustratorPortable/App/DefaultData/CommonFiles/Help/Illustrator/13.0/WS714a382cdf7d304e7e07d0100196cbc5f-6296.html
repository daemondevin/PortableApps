Color

Applying colors to artwork is a common Adobe Illustrator task, and one that requires some knowledge of color models and color modes. When applying color to artwork, keep in mind the final medium in which the artwork will be published, so that you can use the correct color model and color definitions. Experimenting and applying color is easy using the feature-rich Swatches panel, Color Guide panel, and Live Color dialog box in Illustrator.
